# Home

Welcome to Lexsift manual.

## Quickstart

Go to [Installation]({{site.baseurl}}/installation.html) and [Configuration]({{site.baseurl}}/configuration)
if you are already familiar with immersion and Anki and just want to quickly set up Lexsift. If you already have Lexsift set up, you may want to look at [Resources]({{site.baseurl}}/resources.html) to find dictionaries and other files to use with Lexsift.

## Support

Report bugs and request features on [GitHub Issues](https://github.com/MichaelDolzani/Lexsift/issues).

Lexsift is a fork of [VocabSieve](https://github.com/FreeLanguageTools/vocabsieve). Please do not take Lexsift-specific problems to the VocabSieve community channels.

## Contributing

This manual is rather rudimentary as this point. You can edit it [on GitHub](https://github.com/MichaelDolzani/Lexsift/tree/master/docs) and submit a pull request. Large parts of it were inherited from the VocabSieve manual.
